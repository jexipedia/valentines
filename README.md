# Valentines - Interactive Valentine's Day Web App

A beautiful, interactive, and playful web experience for Valentine's Day! 🌹

## Live Demo
[View the live site here!](https://jexipedia.github.io/valentines/)

## Features
- **Animated Flowers & Starfield:** Gorgeous CSS and canvas animations for a romantic atmosphere.
- **Custom Music Player:** Modern, animated player with play/pause, seek, and skip controls. Autoplays a romantic song.
- **Valentine's Modal:** Playful modal asks "Will you be my valentine?" with a Yes/No choice. The No button playfully escapes the cursor!
- **Responsive Design:** Works beautifully on desktop and mobile.
- **Fun Interactions:** Delightful UI surprises for your special someone.

## Getting Started
1. **Clone the repo:**
   ```sh
   git clone https://github.com/jexipedia/valentines.git
   cd valentines
   ```
2. **Open `index.html` in your browser** (or visit the [live demo](https://jexipedia.github.io/valentines/)).

## How to Use
- Enjoy the music and animations.
- Try to click "No" on the modal 😉
- Click "Yes" for a sweet surprise.

## Technologies Used
- HTML5, CSS3, TailwindCSS
- JavaScript (vanilla)
- Canvas & SVG animations
